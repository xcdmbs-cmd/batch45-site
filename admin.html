معاينة الموقع ↗ الدليل

1 ربط حساب GitHub (مرة واحدة)

يُستخدم GitHub لنشر الموقع بشكل دائم (GitHub Pages) ولحفظ الإضافات والتعديلات من داخل هذه اللوحة. لا تُرسل كلمة مرور GitHub أبدًا — نستخدم «توكن» مخصص يمكنك حذفه في أي وقت.

كيف تنشئ التوكن؟
1) افتح github.com/settings/tokens/new (أنشئ حسابًا مجانيًا إن لم يكن لديك).
2) Note: Batch45 Admin — Expiration: 90 يومًا — Scope: اختر repo فقط.
3) اضغط Generate token وانسخه (يبدأ بـ ghp_) ثم الصقه هنا.
غير متصل

🔒 يُحفظ التوكن في متصفحك فقط (localStorage) ولا يُرفع للموقع أو المستودع.

2 النشر الدائم على الإنترنت

بالضغط على الزر أدناه سيقوم النظام تلقائيًا بـ: إنشاء المستودع (إن لم يكن موجودًا) ← رفع جميع ملفات الموقع ← تفعيل GitHub Pages ← إعطاؤك الرابط الدائم.

3 إضافة وتعديل المحتوى

كل حفظ هنا يُرسل مباشرة إلى المستودع ويظهر على الرابط الدائم خلال دقيقة تقريبًا.

⚠️ احترس من الصيغة: أي خطأ في JSON سيمنع الصفحات من العرض. استخدم زر «تحميل الملف» للرجوع للنسخة الحالية.
