# 🎓 بوابة الدفعة 45 — هندسة كيميائية | جامعة الجزيرة

موقع ويب كامل (10 صفحات) خاص بطلاب **الدفعة 45 بقسم الهندسة الكيميائية — كلية الهندسة والتكنولوجيا، جامعة الجزيرة** (الفصل الدراسي الخامس 2026/2027).

- تصميم أكاديمي كحلي/ذهبي، عربي RTL، متوافق مع الجوال.
- بوابة كلمة مرور للدفعة.
- محتوى قابل للتعديل عبر ملفات **JSON** بسيطة — بدون قاعدة بيانات.
- جاهز للنشر على أي استضافة مجانية.

---

## ▶️ أولًا: تشغيل الموقع على جهازك (للمعاينة)

1. انقر نقرًا مزدوجًا على **`تشغيل-الموقع.bat`** (أو اختصار **«بوابة الدفعة 45»** على سطح المكتب).
2. سيُفتح المتصفح تلقائيًا على: `http://localhost:8080`
3. كلمة مرور الدفعة الافتراضية: **`gezira45`**
4. للإيقاف: أغلق نافذة الخادم السوداء (أو Ctrl+C).

> ⚠️ لا تفتح `index.html` مباشرة بالنقر المزدوج — المتصفح يمنع قراءة JSON بدون خادم. استخدم ملف التشغيل دائمًا.

---

## 👥 ثانيًا: إتاحة الموقع للدفعة — 3 خيارات

### الخيار 0 (فوري الآن): رابط إنترنت عام — نفق Cloudflare (بدون حساب)

> شغّل ملف **`START-ONLINE.bat`** (أو **`تشغيل-على-الإنترنت.bat`**) الموجود بجانب مجلد الموقع، وستحصل خلال ثوانٍ على رابط عام مثل:
> `https://xxxx-xxxx.trycloudflare.com` — يفتحه أي شخص من أي مكان في العالم.

- ✅ لا يحتاج حسابًا ولا بطاقة ائتمانية.
- ⚠️ **مؤقت**: يعمل ما دام الجهاز مشغّلًا والنافذة مفتوحة، ويتغيّر الرابط عند كل تشغيل.
- عند إغلاق الجهاز/إعادة التشغيل: شغّل الملف مرة أخرى وشارك الرابط الجديد.
- أداة `cloudflared` محفوظة في مجلد `tools/` بجانب مجلد الموقع.

---

### الخيار 1 (الأفضل والدائم): النشر المجاني على الإنترنت — Netlify
> يمنحك رابطًا مثل `https://batch45.netlify.app` يفتحه أي شخص من أي مكان، مجانًا.

1. **حمّل مجلد الموقع** أو ملف `chemical-engineering-batch45-site.zip` من جهازك.
2. افتح: **https://app.netlify.com/drop**
3. اسحب ملف الـ ZIP وأفلته في الصفحة (أو اسحب مجلد `batch45-site`).
4. انتظر ثوانٍ… سيظهر لك رابط الموقع فورًا.
5. **أنشئ حسابًا مجانيًا** (Sign up) لتثبيت الموقع وعدم انتهائه، ثم اضغط **Claim site**.
6. شارك الرابط مع الدفعة + كلمة المرور.

لتحديث الموقع لاحقًا: من لوحة Netlify ← **Deploys ← Drag and drop** وارفع نسخة جديدة (أو ارفع الـ ZIP).

### الخيار 2: GitHub Pages (مجاني ودائم أيضًا)
1. أنشئ حسابًا على **github.com**.
2. أنشئ مستودعًا جديدًا باسم `batch45-site` واجعله **Public**.
3. اضغط **Add file ← Upload files** وارفع **محتويات** مجلد `batch45-site` (وليس الـ ZIP نفسه).
4. من **Settings ← Pages**: اختر `Branch: main` و`/(root)` ثم **Save**.
5. بعد دقيقة سيكون الرابط: `https://<اسم-حسابك>.github.io/batch45-site/`

> ⚠️ في GitHub Pages (المستودع العام) يمكن لأي شخص رؤية كلمة المرور في `data/config.json`. هذه حماية اجتماعية فقط، وليس أمانًا حقيقيًا.

### الخيار 3 (فوري، بدون إنترنت أو حساب): الشبكة المحلية — نفس Wi-Fi
> مناسب داخل الكلية/القاعة؛ الموقع يعمل من جهازك ويصل إليه زملاؤك على نفس الشبكة.

1. انقر نقرًا مزدوجًا على **`START-SHARE.bat`** (أو **`مشاركة-على-الشبكة.bat`**).
2. ستظهر نافذة فيها رابط مثل: `http://192.168.43.252:8080`
3. شارك هذا الرابط مع زملائك الموجودين على **نفس شبكة الواي فاي**.
4. إذا ظهر تنبيه جدار حماية ويندوز ← اختر **السماح (Allow)** للشبكات الخاصة.
5. يجب أن يبقى جهازك مفتوحًا والبرنامج يعمل طوال فترة المشاركة.

> الرقم `192.168.x.x` قد يتغير حسب الشبكة — انسخه من النافذة في كل مرة.
> ⚠️ جهازك الحالي يعاني من قرص يظهر أعطالًا عتادية؛ الأفضل نشر الموقع على Netlify وعدم الاعتماد عليه كخادم دائم.

## 🛠️ لوحة الإدارة + النشر الدائم (GitHub Pages) — الطريقة الموصى بها

هذه الطريقة تعطيك **رابطًا دائمًا مجانيًا** + **إضافة وتعديل المحتوى من داخل الموقع** بدون لمس أي ملف JSON.

### 1) أنشئ حساب GitHub (مرة واحدة، مجاني)
- افتح https://github.com/signup وسجّل ببريدك.
- لا تحتاج أي إعدادات إضافية.

### 2) أنشئ «توكن» للنشر
1. افتح https://github.com/settings/tokens/new
2. Note: `Batch45 Admin` — Expiration: 90 يومًا.
3. في Scopes اختر **`repo`** فقط.
4. اضغط **Generate token** وانسخه (يبدأ بـ `ghp_`).
> 🔒 لا تشارك التوكن مع أحد، ويمكنك حذفه من نفس الصفحة في أي وقت.

### 3) افتح لوحة الإدارة
- شغّل الموقع محليًا ثم افتح: **`http://localhost:8080/admin.html`**
- (أو من الرابط المنشور: `<رابط-الموقع>/admin.html`)

### 4) اربط وانشر (مرة واحدة)
1. أدخل: اسم حساب GitHub + اسم المستودع (افتراضي `batch45-site`) + التوكن.
2. اضغط **«حفظ واختبار الاتصال»**.
3. اضغط **«🚀 انشر الموقع الآن (دائم)»** — سيقوم تلقائيًا بـ:
   - إنشاء المستودع إن لم يكن موجودًا.
   - رفع جميع ملفات الموقع.
   - تفعيل GitHub Pages.
   - إعطاؤك الرابط الدائم: `https://<username>.github.io/batch45-site/`
4. انتظر 1–2 دقيقة حتى يعمل الرابط.

### 5) أضف وعدّل من داخل الموقع
من نفس اللوحة (تبويبات):
- 📰 **الأخبار**: إضافة/تعديل/حذف.
- 📚 **المقررات والملفات**: إضافة مقرر، إضافة ملفات، و**رفع PDF** مباشرة (يُرفع إلى `assets/files/`).
- 🎉 **الفعاليات** و 👥 **الأعضاء**.
- 🧩 **JSON مباشر**: تحرير أي ملف بيانات (الجدول، الأسئلة، المنتدى، كلمة المرور…) مع تحقق من الصيغة.

> كل «حفظ» يُرسل تعديلًا (commit) إلى GitHub ويظهر على الرابط الدائم خلال دقيقة تقريبًا.

### ملاحظات مهمة
- لوحة الإدارة **غير مرتبطة بقوائم الموقع** — احتفظ برابطها لنفسك.
- مستودع GitHub Pages المجاني يكون **عامًا** (المحتوى ظاهر لأي شخص)، فلا تضع بيانات حساسة حتى مع كلمة المرور.
- التوكن يُحفظ في متصفحك فقط (localStorage) ولا يُرفع إلى المستودع.
- بعد أول نشر: أي تعديل من اللوحة يُحدّث الموقع الدائم مباشرة؛ لا حاجة لإعادة النشر إلا عند تغيير ملفات الموقع نفسها (استخدم «تحديث كل الملفات»).

## 🔐 تغيير كلمة المرور (مهم قبل المشاركة)

افتح `data/config.json` وعدّل:

```json
"auth": { "enabled": true, "password": "كلمة_سر_الدفعة" }
```

- غيّر `gezira45` إلى كلمة مرور تعرفها الدفعة فقط.
- لتعطيل البوابة تمامًا: اجعل `"enabled": false`.
- ⚠️ ملاحظة أمان: في المواقع الثابتة تُخزَّن كلمة المرور داخل ملف يمكن لأي شخص متمكّن قراءته (حماية شكلية/اجتماعية).
  - للحماية الحقيقية: Netlify Password Protection (مدفوع)، أو **Cloudflare Access** (مجاني حتى 50 مستخدمًا)، أو لاحقًا حسابات أعضاء عبر Supabase.
  - لا تضع في الموقع بيانات حساسة (أرقام هواتف خاصة، درجات…) ما لم تضبط حماية حقيقية.

## ✏️ تعديل المحتوى

كل الملفات نصية بصيغة JSON. عدّلها بأي محرر نصوص (Notepad / VS Code) ثم احفظ وحدّث الصفحة.

### 1) الأخبار — `data/news.json`
```json
{
  "id": "news-08",
  "pinned": true,
  "category": "إعلان",
  "title": "عنوان الخبر",
  "date": "2026-12-01",
  "author": "مكتب الدفعة",
  "excerpt": "ملخص يظهر في القائمة.",
  "body": "<p>النص الكامل داخل نافذة الخبر.</p>"
}
```
- `pinned: true` يثبّت الخبر في الأعلى. الفئات: إعلان / أكاديمي / فعالية / هام.

### 2) المكتبة — `data/courses.json`
أضف ملفًا داخل `files`:
```json
{ "title": "ملزمة المحاضرة 6", "kind": "PDF", "size": "1.2 م.ب", "date": "2026-12-02", "url": "https://drive.google.com/..." }
```
- ضع رابط الملف (Google Drive / Dropbox / رابط مباشر) في `url`.
- أو ضع الملف داخل `assets/files/` واستخدم مسارًا نسبيًا `"assets/files/lecture6.pdf"`.
- الرابط الفارغ `""` يظهر بعلامة «قريبًا».
- تنسيق التاريخ: `YYYY-MM-DD`.

### 3) الجدول — `data/schedule.json`
- `days` أيام الأسبوع، `periods` الحصص، وكل `entry` له `day` (من 0) و`period` (من 0).
- `exams` جدول الامتحانات: `course`, `date`, `time`, `place`, `type`.

### 4) بنك الأسئلة — `data/exams.json`
أضف لكل مقرر عناصر داخل `items` بنفس نمط ملف المكتبة.

### 5) الفعاليات — `data/events.json`
`id`, `title`, `date`, `time`, `place`, `type`, `desc` — يظهر تلقائيًا في التقويم.

### 6) الأعضاء — `data/members.json`
```json
{ "name": "اسم الطالب", "role": "عضو", "interests": ["اهتمام"], "joined": "2024", "contact": "https://t.me/username" }
```
لا تضع بيانات تواصل إلا بموافقة العضو.

### 7) المنتدى — `data/forum.json`
المواضيع الافتراضية. المواضيع والردود الجديدة تُحفظ في **متصفح الزائر فقط** (localStorage) لأن الموقع ثابت بلا خادم.
للنقاش المشترك الحقيقي لاحقًا: اربط الموقع بخدمة مجانية مثل **Supabase** (قاعدة بيانات + حسابات).
